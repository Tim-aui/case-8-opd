# Связь Use Case → экран — Кейс № 8

**Версия:** 1.3<br>
**Основа:** пять Use Case из официального чек-листа Хакатона 1.

## Матрица

| UC | Актор | Форма 1С | Экран веба | Ключевые шаги и результат |
|---|---|---|---|---|
| UC-08-1 Выдать книгу | Библиотекарь | Форма оформления выдачи | Карточка читателя → Выдача / возврат | Выбрать читателя и свободный экземпляр, указать срок, подтвердить; создаётся активная выдача |
| UC-08-2 Принять возврат | Библиотекарь | Форма оформления возврата | Выдача / возврат | Найти активную выдачу, указать дату возврата, подтвердить; экземпляр освобождается |
| UC-08-3 Импортировать данные | Администратор | Обработка импорта CSV и протокол импорта | — | Выбрать CSV книг, читателей и выдач, запустить проверку, получить протокол; корректные записи загружаются без дублей |
| UC-08-4 Сформировать отчёт о просрочках | Библиотекарь, администратор | Форма отчёта «Просрочки» | Просрочки + KPI | Выбрать дату и фильтры, сформировать строки и показатели отчёта |
| UC-08-5 Экспортировать CSV | Библиотекарь, администратор | Команда выгрузки отчёта «Просрочки» | Просрочки → «Экспорт CSV» | Сформировать отчёт и выгрузить его в согласованном формате |

Импорт выполняется только в 1С; в колонке «Экран веба» для него стоит «—». Экспорт доступен обеим рабочим ролям на экране «Просрочки».

## Тексты для сценария «Выдать книгу»

| Ситуация | Текст сообщения | Поведение |
|---|---|---|
| Успешная выдача | «Книга выдана до ДД.ММ.ГГГГ» | Закрыть форму и обновить данные |
| Экземпляр уже выдан | «Экземпляр уже выдан другому читателю. Выберите доступный экземпляр» | Не создавать выдачу; сохранить читателя и даты |
| Читатель не найден | «Читатель не найден. Выберите существующего читателя» | Не создавать выдачу; подсветить поле читателя |
| Экземпляр не найден | «Экземпляр книги не найден в каталоге» | Не создавать выдачу; подсветить поле экземпляра |
| Неверные даты | «Дата планового возврата не может быть раньше даты выдачи» | Не создавать выдачу; подсветить срок возврата |
| Ошибка сохранения | «Не удалось оформить выдачу. Проверьте данные и повторите попытку» | Сохранить введённые данные и показать повтор действия |
